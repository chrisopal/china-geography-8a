# 沙盘交互优化

目标：让八年级学生通过转动、比较和操作理解空间关系，保留 81 个知识点、问答、学习记录与配音。参考 WeduLab 的等高线课堂和水循环课堂的交互组织，不复制实现或素材。

参考（2026-10-10 实际浏览）：
- https://wedulab.com/labs/contour：旋转、缩放、右键平移；章节切换配合切面扫描；同场景不同观察视角。
- https://wedulab.com/labs/water：分步过程、可调参数、粒子展示和随堂问题。

选择：改进已有无依赖 Canvas 投影沙盘。仅调整 UI 不能解决手势和讲解脱节；更换完整三维引擎需要新增依赖且扩大回归范围。本轮不引入依赖，不将此渲染器称为 WebGL 或实测地形。

## 交互与画面

- 惯性旋转、渐进缩放、目标点缩放、右键/Shift 平移、双指缩放和平移、双击聚焦、预设视角、全屏。
- 海洋深蓝 #0a151b、面板 #101e25、植被 #b5e7bc、水流 #65c8c1、地形/分水岭 #e8bd83；保留课程视觉身份。中文系统字体优先，工具文字至少 11px。
- 中央沙盘占主要面积；顶端视角工具，右侧缩放与暂停；底端观察目标和指标；外部保留讲解、练习和资料。
- 不为切换知识点硬重置镜头。讲解跟随模式应用显式观察步骤；手动操作进入自由探索，须点击跟随才恢复镜头联动。
- 暂停动态和配音暂停分别管理；过期配音不切换场景或启动旧步骤。减少动态偏好禁用惯性/渐变和自动粒子运动。

## 三条操作主线

1. 三级阶梯：全国地势→侧面高度比较→东流与阶梯落差；在两种视角间比较。
2. 季风：切换冬夏→比较海陆风向→观察湿润气流与降水差异；零和一百是两个季节情景。
3. 分水岭：两侧落雨→追踪各自下坡汇流→辨认不同流域；明确地表汇流示意。

每条主线保留先预测、亲手操作、观察解释、迁移测验。改动集中 renderer.js、app.js、index.html、styles.css，必要时增加针对交互的验证脚本。

## 验证

相机缩放边界、指针取消、多指结束无误选、暂停/恢复、自由探索不被异步状态或配音抢镜头；三个重点实验的可见反馈；全部课程访问及练习回归；桌面与 390px 布局截图；浏览器控制台；Worker 构建和 API 回归。移动双指以 Chromium 触摸事件模拟，不能冒称实体设备验证。
