# 全场景过程实验

用户将季风的视觉改进扩展到全部地理沙盘，特别指出“雨水去哪儿”同样只有单线。参考 WeduLab 水循环与等高线课堂的因果过程、动画控制与条件对比，但继续遵守现有无依赖实现与教学示意边界。

七类场景：全国地形继续用专题、视角与夸张参数比较；季风使用宽幅气流场、两类水汽来源和云雨；流域演示降雨—分散坡面汇流—支流/干流—出口；土地呈现保护程度对径流/下渗的影响；能源呈现设备与发电输电；运输使用与方式对应的移动载具；生态呈现污染输入与修复后的变化。

所有动态场景共用暂停、0.5/1/2 倍速与动画重播。速度只改变示意动画，不改变现实物理量。情景按钮与参数保持一致，观察提示解释当前条件与可见结果。保持自由镜头、键盘、减少动态、配音和练习逻辑。

验收重点：过程在画面中实际可见；雨滴到径流连贯且不越过分水岭；切参数有可辨认的几何/粒子变化；暂停静止；重播保留场景参数与相机；触屏与窄屏不遮挡；全部课程与已有 API 回归。代码和截图由主代理集中复核后发布。
